# Conventions (Layer 3 reference) — redirect

The code rules are canonical in the repo's own conventions file — a root conventions file where the
repo keeps one, otherwise its `AGENTS.md`. They live there once; this file does not copy them.

The Build stage loads that file directly — read it for code style, what to avoid, and git. For
app/package-scoped deltas, also read the subtree `AGENTS.md` files, where the repo has them. Which
file it is for this repo is named in `_shared/project-rules.md` → Knowledge → Code rules.
